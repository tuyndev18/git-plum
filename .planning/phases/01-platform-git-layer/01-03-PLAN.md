### `@tauri-apps/plugin-store` 2.4.5 — API cần dùng

```typescript
import { load, type Store } from '@tauri-apps/plugin-store'

// Mở (hoặc tạo) một tệp store. autoSave: true ghi xuống đĩa sau mỗi lần set.
const store: Store = await load('recent-repos.json', { autoSave: true })

await store.get<T>(key: string): Promise<T | undefined>
await store.set(key: string, value: unknown): Promise<void>
await store.save(): Promise<void>
```

Lưu ý phiên bản: crate Rust `tauri-plugin-store` và npm `@tauri-apps/plugin-store` phải
khớp theo minor, nếu không `tauri build` **từ chối chạy**. Hiện đã ghim npm `2.4.5`;
không nâng, không hạ.

Plugin đã được khởi tạo trong `src-tauri/src/lib.rs`:
`.plugin(tauri_plugin_store::Builder::new().build())`
và quyền `store:default` đã có trong `src-tauri/capabilities/default.json`.
**Không cần sửa Rust cho plan này.** Nếu trong lúc làm phát sinh lỗi
"command not allowed", đó là dấu hiệu thiếu quyền — Tauri v2 hỏng **im lặng ở thời điểm
chạy** khi thiếu capability, đây là chỗ cần kiểm tra đầu tiên chứ không phải mã frontend.

### `src/stores/repoStore.ts` — điểm móc vào

```typescript
openRepository: async (path) => {
  set({ isOpening: true })
  try {
    const info = await ipc.openRepository(path)
    set((s) => ({ byRepo: { ...s.byRepo, [info.id]: { info, currentBranch: null, error: null } },
                  activeRepoId: info.id, isOpening: false }))
    await get().refreshBranch(info.id)      // ← ghi nhớ repo ngay sau dòng này
  } catch (e) { set({ isOpening: false }); throw e }
}
```
